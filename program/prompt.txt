SECTION 2 — PARSING RULES (INPUT → JSON)
════════════════════════════════════════

[R1] VERSION DETECTION
Each version block starts with: ## 【N 學年度第 S 學期版本】
→ academic_year = N (integer), semester = S (integer)

[R2] COURSE GROUPS
- 必修 courses → id: "core_required"
- 必選修 courses → id: "core_elective"
- 選修 courses → id: "elective"
- Undivided core → id: "core"
- selection_rule:
  - Must take ALL subjects → {"type": "all"}
  - Must pick N SUBJECTS (科目數) → {"type": "pick_n", "pick": N}
  - Must reach credit minimum only → {"type": "min_credits"}
- credit_requirement: ALWAYS an object with "min". NEVER null or missing.
  If the text doesn't state a specific minimum, use {"min": 0}.
- If the group requires a minimum of starred (＊) elective credits, add "required_tags":
  Example: "選修至少27學分，其中含打＊號的選修課程至少6學分"
  → "credit_requirement": {"min": 27, "required_tags": [{"tag": "starred", "min_credits": 6}]}
- If text says "每一學程科目僅採計一門課程學分":
  each program_subject gets ONE alternative chosen by the student

[R3] SUBJECTS AND ALTERNATIVES
- program_subject = the abstract subject name listed in the program
- alternatives = concrete course names that satisfy that subject
  (from columns labeled 採認課程名稱 or 可用下列課程替代)
- ANY ONE alternative satisfies the subject requirement
- NEVER truncate: include ALL listed alternatives

[R3a] COURSE NAME SPLITTING — parenthetical alternatives

When a course name contains the pattern "X（A）或（B）" or "X(A)或(B)",
this means TWO (or more) separate courses. Split into individual alternatives.

TRIGGER SIGNAL: the substring 或（ or 或( appearing inside the name → ALWAYS split.
NO-SPLIT SIGNAL: no 或（ pattern present → keep name as-is.

EXAMPLES:
  Input:  "工程數學（一）或（二）"
  Output: two alternatives → "工程數學（一）"  and  "工程數學（二）"

  Input:  "微積分（上）或（下）"
  Output: two alternatives → "微積分（上）"  and  "微積分（下）"

  Input:  "普通物理（一）或（二）或（三）"
  Output: three alternatives → "普通物理（一）", "普通物理（二）", "普通物理（三）"

  Input:  "工程數學（含微積分）"
  Output: keep as-is → "工程數學（含微積分）"   ← no 或（ present, do not split

  Input:  "微積分（理工）"
  Output: keep as-is → "微積分（理工）"         ← no 或（ present, do not split

Each split result inherits the same departments, credits, and note as the original entry.

[R3b] TAGS (＊ starred electives)
- If a course name starts with ＊ (full-width asterisk) or the text mentions "打＊號",
  add "tags": ["starred"] to that subject.
- Example: "＊軟體工程" → program_subject: "軟體工程", tags: ["starred"]
- The ＊ symbol should be REMOVED from the program_subject and alternative course names.
- Example: "＊物件導向程式設計" → program_subject: "物件導向程式設計", tags: ["starred"]
- If a subject has no ＊, set "tags": [] or omit the field entirely.

[R4] DEPARTMENTS — apply rules in this exact priority order:

  PRIORITY 1 — ANY of these phrases → departments: []  (means any dept is valid)
    "各開課系所", "校內各系", "各系所", "各系", "合開" (with no specific dept listed)

  PRIORITY 2 — If a PRIORITY 1 phrase appears WITH specific depts:
    e.g. "各開課系所、資工系" → departments: []  ← PRIORITY 1 wins, ignore specific depts

  PRIORITY 3 — 跨院選修(...) pattern:
    "跨院選修(工)", "跨院選修(館)" → departments: ["跨院選修"]  ← drop the parenthetical suffix

  PRIORITY 4 — Multiple specific departments:
    Separated by 、 → list all:  "電機系、材光系" → ["電機系", "材光系"]
    Separated by 或 → list all:  "應數系或電機系" → ["應數系", "電機系"]

  PRIORITY 5 — Single specific department:
    Expand short forms: "應數" → "應數系",  "資工" → "資工系"
    Keep graduate dept names as-is: "電機碩", "資工碩"

  ✗ WRONG:   departments: ["各開課系所"]
  ✓ CORRECT: departments: []

[R5] CREDITS
  - Integer value  → use integer:  3
  - Range          → use string:   "2-3"
  - Variable       → use string:   "依開課學系規定"
  - NEVER use 0 as credits. If the credit value is unspecified or variable, use the string "依開課學系規定".
  - If the text says something like "3(4)" meaning 3-4 credits, use the string "3-4".
  - If the text says credits differ by dept, use the most common value as integer.

[R6] PROGRAM NAME
  - Use the "primary program name hint" from the user message as program_name
  - Override ONLY if the document body states a clearly different official name
  - Strip ALL of the following from program_name:
      全英語學程 / 停止受理 / English translations / extra descriptions
  - Keep it minimal:
      ✓ "與社會交往的表演藝術微學程"
      ✗ full filename with suffixes

[R7] SPECIAL STATES
  - 停止受理 present in document → is_discontinued: true, fill discontinued_date
  - Renamed program             → former_name: "original name"
  - Non-course requirements (e.g. 需參加說明會) → non_course_requirements array
  - Credit transfer limits, external credit rules, waivers → requirements fields

[R8] WAIVER (抵免)
  - If the text says students can waive/transfer credits from prior courses:
    set waiver.allowed = true and list each waiver option in waiver_alternatives.
  - Each waiver_alternative has: condition (what qualifies), credits_granted (integer), note (extra info or null)
  - Example: "以前修習課程及學分數之抵免，由本學程負責人認定"
    → waiver: {"allowed": true, "max_credits": null, "note": "...", "waiver_alternatives": [{"condition": "由本學程負責人認定", "credits_granted": 0, "note": null}]}
  - If no waiver is mentioned: waiver: {"allowed": false, "max_credits": null, "note": null, "waiver_alternatives": []}
  - If a specific credit limit is stated: "最多可折抵6學分" → max_credits: 6

[R9] SUBJECT-LEVEL WAIVER
  Some programs allow per-subject waiver alternatives (e.g. specific certifications or exams that can replace a course).
  If the text lists specific alternatives for waiving a subject, add a "waiver" field to that subject:
  Example text: "TOEIC 750分以上可抵免英文(一)"
  → subject: {"program_subject": "英文(一)", "alternatives": [...], "waiver": {"allowed": true, "waiver_alternatives": [{"condition": "TOEIC 750分以上", "credits_granted": 2, "note": null}]}}
